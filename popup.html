How to use
Excel format required:
• Sheet name: PAN Filing Status (or first sheet)
• Required column: PAN_NUMBER
• Optional columns auto-filled: FILING_STATUS, FILER_YEAR, REMARKS
• Already-resolved PANs are skipped automatically
How it works:
1. Extension opens ird.gov.np in a background tab
2. Fills each PAN into the search form automatically
3. Reads the result (FILER / NON-FILER) from the page
4. Waits the configured delay, then checks the next PAN
5. If CAPTCHA appears, you are prompted to solve it once
CAPTCHA handling:
When CAPTCHA appears, a notice shows in this popup. Click the link to switch to the IRD tab, solve the CAPTCHA, then return here — checking resumes automatically after 30 seconds.
